# 🏢 Business Empire: RichMan (Indonesia Edition)

Game simulasi bisnis dan *idle tycoon* konglomerat terinspirasi dari **Business Empire: RichMan**, dengan mata uang **Rupiah (Rp)** dan modal awal **Rp 8.000.000** (~$500).

---

## 🎮 Cara Menjalankan Game

Anda memiliki dua opsi mudah untuk memainkan game ini:

### Opsi 1: Buka Langsung (Paling Cepat)
Cukup buka file `index.html` dengan klik ganda (*double-click*) di File Explorer untuk langsung memainkannya di Google Chrome, Microsoft Edge, atau browser favorit Anda.

### Opsi 2: Menggunakan Local Server (Node.js)
1. Buka Terminal / PowerShell di folder ini.
2. Jalankan perintah:
   ```bash
   node server.js
   ```
3. Buka browser dan kunjungi: **`http://localhost:3000`**

---

## 🚀 Publikasi ke GitHub & Memainkan Online (GitHub Pages)

Game ini 100% *Client-Side* (HTML, CSS, Vanilla JS murni) tanpa memerlukan database server eksternal, sehingga data setiap pemain tersimpan aman dan terisolasi di perangkat/browser masing-masing (*Local Storage*).

### Cara Upload ke GitHub & Aktifkan GitHub Pages:
1. Buat repositori baru di akun GitHub Anda (misal: `business-empire-game`).
2. Upload semua file dari folder ini ke repositori tersebut.
3. Di halaman repositori GitHub, buka tab **Settings** > **Pages** (di menu sebelah kiri).
4. Pada bagian **Build and deployment** > **Branch**:
   - Pilih branch `main` (atau `master`).
   - Folder pilih `/ (root)`.
   - Klik **Save**.
5. Tunggu sekitar 1-2 menit, GitHub akan memberikan link website game Anda (misal: `https://username.github.io/business-empire-game/`).
6. Siapa pun yang membuka link tersebut lewat handphone langsung dapat memainkan game dengan data masing-masing mulai dari nol (0).

## 🌟 Fitur Utama

1. **🏢 Kerajaan Bisnis Realistis:**
   * **Bisnis Awal:** Toko Retail & Kelontong, Armada Taksi & Ojol, Kafe & Restoran Kekinian.
   * **Bisnis Menengah:** Brand Fashion Distro, Ekspedisi & Logistik Kargo.
   * **Konglomerasi & Perbankan:**
     * **Bank Komersial Swasta:** Anda bisa menyetor dana brankas (*vault*), mengatur **Suku Bunga Deposito** nasabah dan **Suku Bunga Kredit Pinjaman** untuk memaksimalkan margin laba per jam.
     * **Studio Game & Software House.**
     * **Korporasi Tambang & Minyak.**
     * **Agensi Antariksa & Dirgantara (Space Agency).**

2. **📈 Pasar Modal & Kripto:**
   * **Bursa Saham:** Saham bluechip lokal dan teknologi dunia (BBCA, TLKM, ASII, ANTM, GOTO, NVDA, AAPL) dengan grafik tren harga dan dividen pasif per jam.
   * **Crypto Exchange:** Trading koin volatil (Bitcoin, Ethereum, Solana, Dogecoin) dengan pergerakan harga dinamis.

3. **🏠 Portofolio Properti (Real Estate):**
   * Mulai dari Rumah Kost di Jogja, Apartemen di Jakarta, Ruko Surabaya, Villa di Bali, hingga Penthouse Manhattan dan Pencakar Langit Dubai yang menghasilkan uang sewa pasif per jam.

4. **🏎️ Kemewahan & Gaya Hidup (*Luxury*):**
   * Koleksi jam tangan Rolex, supercar Porsche, Bugatti Chiron, helikopter Airbus, private jet Gulfstream, superyacht 110 meter, hingga Pulau Pribadi Raja Ampat untuk mendongkrak prestise dan gelar Net Worth.

5. **⚡ Mekanika Waktu & Progres:**
   * **Pengatur Kecepatan:** 1x, 5x, 60x, atau tombol **⏩ +1 Jam** untuk fast-forward.
   * **Proyek Freelance Cepat (Clicker):** Klik tombol kerja freelance kapan pun Anda membutuhkan uang tunai kilat di awal permainan.
   * **Auto-Save & Offline Earnings:** Progres tersimpan otomatis di browser, dan Anda tetap mendapatkan cuan saat game sedang ditutup.
   * **Audio SFX Built-in:** Efek suara kasir dan klik menggunakan Web Audio API tanpa perlu file eksternal.
